# Week 1 – Cybersecurity Foundations

This repository contains the completed training materials for Week 1 of the cybersecurity foundation program. It includes four structured tasks covering networking fundamentals, Linux and system security, threat and vulnerability identification, and a basic security assessment.

## Overview

This week focuses on building a strong foundational understanding of cybersecurity principles and practical security awareness. The exercises are designed to help learners understand how systems communicate, how Linux security controls work, how common threats and vulnerabilities are identified, and how basic assessments are performed in a structured and professional manner.

## Task 1.1 – Networking Fundamentals

This task covers the core concepts of networking, including communication between devices, IP addressing, protocols, and the role of network infrastructure in cybersecurity. It establishes the foundation needed to understand how networks function and how they can be protected.

## Task 1.2 – Linux & System Security

This task introduces Linux system basics and the security controls that help protect operating systems and user environments. It focuses on access control, permissions, configuration awareness, and basic system hardening principles.

## Task 1.3 – Threat & Vulnerability Identification

This task explores common threats, vulnerabilities, and the relationship between weaknesses and potential risk. It helps learners recognize how security issues can arise and how they may affect systems, networks, and business operations.

## Task 1.4 – Basic Security Assessment

This task introduces a structured approach to evaluating a system or environment using basic assessment methods. It emphasizes objective observation, documentation, and the identification of areas that may need follow-up review or additional security controls.
