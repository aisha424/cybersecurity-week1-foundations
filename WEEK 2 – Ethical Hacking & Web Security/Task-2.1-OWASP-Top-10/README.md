# Task 2.1 – OWASP Top 10

This task focused on the OWASP Top 10 and the most common weaknesses found in web applications. The goal was to understand the main categories of risk, how they can affect a system, and why they are important in security assessments.

## Summary

The OWASP Top 10 covers a range of issues such as injection, broken authentication, sensitive data exposure, security misconfiguration, and cross-site scripting. These vulnerabilities are important because they are common, often exploitable, and can lead to serious risk if not addressed.

## Learning Focus

- Review and understand the OWASP Top 10 categories
- Recognize the real-world impact of common web vulnerabilities
- Link vulnerabilities to practical examples and security testing
- Prepare for deeper analysis in the later tasks of this week

## Notes

This task forms the foundation for the rest of Week 2, especially the practical vulnerability testing and report writing that followed.
