# Task 2.3 – Authentication & Session Analysis

This task focused on weaknesses related to authentication, input validation, and session management. The objective was to review how a web application handles login flows, stored client-side data, and session-related information.

## Focus Areas

- Authentication weakness analysis
- Input-validation weakness review
- Session-management testing and observation
- Review of authentication-related values stored in browser local storage

## Security Note

The local storage review involved authentication-related data. Only the redacted screenshot was used for documentation, and no actual credential, password, or JWT value was exposed in the project materials.

## Outcome

This task improved understanding of how weak validation and poor session handling can create security risks in web applications, even in a controlled educational environment.
