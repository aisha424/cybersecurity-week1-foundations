# Task 2.4 – Penetration-Testing Report

This task involved turning the findings from Week 2 into a short penetration-testing style report. The report was based on the actual web security issues identified during the controlled practice exercises and written in a structured assessment format.

## Report Structure

The report includes a summary of the environment, the methods used, the identified vulnerabilities, the evidence collected, and the key conclusions. It was prepared to reflect the findings from the week without overstating the scope or claiming a full exhaustive penetration test.

## Main Points Included

- OWASP Juice Shop as a legal training environment
- Web vulnerabilities identified during testing
- Supporting evidence and findings summary
- Security recommendations and assessment conclusions

## Outcome

This final task helped connect the technical findings to a professional-style documentation format and made the Week 2 work easier to present and review.
